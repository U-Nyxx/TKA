## 🕐 Alur Latihan Malam Ini (B. Indonesia — PRIORITAS)

1. **Baca** `01-bahasa-indonesia/materi.md` (± 45 menit). Pahami 3 kompetensi + teknik per pola soal.
2. **Istirahat 10 menit.**
3. **Kerjakan `soal.md` (Simulasi 1):** atur timer **75 menit**, tanpa buka kunci, seolah sedang ujian.
4. **Kirim jawabanmu ke chat** dengan format:
   ```
   A: 1.A 2.C 3.B 4.D 5.- ... 30.B
   ```
   (kalau ada yang nggak yakin, tulis `-` atau jawaban awalmu)
5. Gw kroscek → kasih **skor + analisis kesalahan per kompetensi**.
6. Kalau masih bertenaga → kerjakan `soal-2.md` (Simulasi 2), atau besok pagi [H-0] baca ulang pembahasan saja lalu **tidur cukup**.
